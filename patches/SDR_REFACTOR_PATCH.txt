REGRAS

Se tag em:
- conversando
- respondido
- indicação
- caro evento
- linkedin
- lead trafego

=> nunca entra no WA hunter.

Se lead_trafego:
=> strategy = inbound_warm

Se clicked_warm / email click / form / resposta positiva:
=> strategy = warm
=> parar hunter
=> mover para Conexão Realizada ou Qualificado conforme intent

Se reunião criada:
=> strategy = meeting
=> mover para Reunião Agendada

Se sem_interesse / numero_errado / menu_bot:
=> strategy = blocked
=> adicionar blocklist
=> não enviar mais WA

MENU BOT:
Adicionar tag whatsapp_bot ou menu_bot.
Adicionar blocklist.
NÃO mover para perdido.

INDICAÇÃO:
Se detectar telefone/email novo:
- criar nova Person
- criar nota no deal original
- bloquear telefone de quem indicou
- tag indicação
- não continuar hunter no contato original

ANTI-DUPLICIDADE

Antes de qualquer WhatsApp:
- checar data/wa_strategy_state.json
- chave: deal_id:phone
- se sent_steps contém hunter_1, não reenviar abertura
- se status blocked/warm/completed/paused, não enviar hunter

Formato:

{
  "deal_id:phone": {
    "strategy": "hunter|warm|meeting|blocked",
    "hunter_step": 1,
    "sent_steps": ["hunter_1"],
    "last_sent_at": "...",
    "status": "active|warm|blocked|completed",
    "reason": ""
  }
}
